## 怎么玩

双击仓库根目录 `启动桌面前线.command`，或运行 `python3 tools/run.py`，打开 `http://127.0.0.1:8768/`。已有页面刷新后检查版本 0.6.0。

- 控制台顶层选「游戏 AI」或「DeepSeek LM」观看自动作战；LM 默认每局最多 120 次请求，并发 3，约 3 秒重新决策。
- 「蓝军进一楼 / 蓝军上二楼 / 蓝军撤出小楼」控制建筑使用。
- 选绿色阵营，出现敌坦克后点「接管反坦克炮」；需要放弃操作时点「弃炮」。当前炮采用单兵操作；自动模式也能自行选择。
- 1/2/3 接管阵营，左键选择/框选，右键地面移动；中键拖动、方向键平移，滚轮缩放；C 找掩体、R 撤退、A 交回游戏 AI。

## 动作和接口

13 个可执行战术命令：`move, capture, cover, flank, retreat, hold, attack, grenade, posture, man_at_gun, leave_gun, garrison, leave_building`。LM 另有 `wait`，只是保持当前意图。坦克不支持步兵姿态、手雷或设施操作。

完整人物、武器、坦克、炮组和建筑状态序列、参数及示例：[AGENT_ACTION_STATES.md](AGENT_ACTION_STATES.md)。机器目录：[action-catalog.json](../data/action-catalog.json)，服务端 `GET /api/action-catalog`。接入方法：[LM_CONTROL.md](LM_CONTROL.md)。美术与尺寸：[ASSET_EQUIPMENT.md](ASSET_EQUIPMENT.md)。

## 实际边界

这是可玩的战术原型。炮组当前是一名操作员，无两人装填协作；火炮按短距离安全牵引与固定部署射界操作，炮弹后备暂不限量。房屋是开放屋顶观察模型，按分件破坏与楼板失效坍塌，没有结构工程求解。模型掌握公开全局状态，没有战争迷雾或团队长程指挥通信。Jev 仍可通过开放 Agent 状态/命令协议接入，没有声称接入不存在的 Jev SDK。
