# AI 桌面对抗演示

在保留策划网页、战术执行、独立游戏入口的基础上，实现双人站立桌面演示：模型按意图生成受约束关卡，编辑器逐项展现布局，双方从桌边逐兵入场，游戏 AI / LLM 按真实来源指挥，夺旗至胜负，记录战局并可将复盘用于下一关。

使用既有玩具兵、装备和场景组件；新增程序化站立人类与桌面呈现，不替换原素材。生成过程先取得并验证方案，再按可审计步骤执行，不能将本地预设伪装为 JEV。JEV 未配置时只声明接口兼容。

验收：真实 Godot 场景两名站立玩家、桌边待命单位、未部署不交战/占旗、逐兵进入后激活、仅绿红参战、胜负冻结、逐步建场可暂停、控制台录像或明确浏览器限制、回放时间线与战后报告/下一关关联。预定预算 60 分钟、最多 3 轮修复；无外部密钥时用显式本地方案做机制验收。
