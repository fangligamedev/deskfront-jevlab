## 当前限制

关卡是先生成完整方案再逐项执行。两名人类为程序化代理模型，尚非精细 Blender 人物和手部互动。坦克仅在桌缘展示，当前演示未包含装甲派遣；反坦克炮和建筑沿用地图位置。任意新关卡仍可能平局，导航校验不是战术平衡证明。

报告是模型分析：已校验结构和引用 Tick，不能把相关性推断当成经证实的战术因果。录制依赖用户选择浏览器窗口和权限，尚未剪辑或发布影片。独立浏览器窗口与原网页不会迁移正在运行的局；首次新窗口开新局，当前页面放大可保留本局。

## 使用

运行 `python3 tools/run.py`，打开 `http://127.0.0.1:8768/?view=demo`。本次隔离演示已准备在 `http://127.0.0.1:8792/?view=demo`，用于避免接管其他运行中的游戏窗口。

展开准备区选择生成/排练 → 录制演示 → 连续执行步骤 → 等待胜负 → 复盘并生成下一关。暂停后先点“继续”；想查看战术命令和日志，切换“战术执行”或“策划网页”，不会重开本局。
