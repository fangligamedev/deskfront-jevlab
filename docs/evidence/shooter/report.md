# 单兵射击模式交付报告

在原 RTS 战斗上新增可切换的第三人称与第一人称步兵接管。当前办公室战场、办公用品掩体、根运动和原有战斗模拟均直接复用。玩家射击会消耗弹药，被掩体阻挡并造成实际伤害；低掩体站起、高掩体绕角、换弹、手雷和冲锋都已接入。

只接管选中的步兵，队友继续沿用阵营控制模式。AI/LLM 无法抢走玩家单位，退出接管后恢复原有控制。死亡、换地图、换装备等情形会释放接管与鼠标；投雷途中退出仍会完成一次真实投掷。

## 使用

打开本地游戏 `http://127.0.0.1:8768/?view=execution`，刷新后选中步兵，点击「第三人称接管 / 第一人称接管」或在画布内按 F6，再点击画面锁定鼠标。

WASD 移动，Shift 冲锋，鼠标瞄准，左键射击，右键瞄准/探身，E 掩体，C 蹲姿，R 换弹，G 手雷，V 切换人称，Tab 返回 RTS，Esc 释放鼠标。完整说明见 [单兵模式文档](../../SHOOTER_MODE.md)。

## 当前边界

这是可操作的单兵玩法首版，尚未制作独立第一人称手臂动画。镜头内武器复用现有模型，实际弹道仍从角色的真实枪口发射。没有新增八方向持枪移动素材：身体朝行进方向；冲锋及侧后方向移动时限制开火，停止后可自由瞄准。坦克、操炮和驻楼状态需要退出设施后再接管普通步兵。没有增加联网射击同步。
