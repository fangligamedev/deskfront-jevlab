# RTS 镜头与战术操作

入口：[战术执行](http://127.0.0.1:8768/?view=execution&v=rts-controls)。点击战场后，键盘操作由游戏接收。左键选择士兵会切换该阵营为玩家接管。

## 选择与命令

| 操作 | 功能 |
| --- | --- |
| 左键点击士兵 | 单选；可只控制一名士兵 |
| 左键拖出方框 | 框选；支持任意拖动方向和紧框单兵 |
| Shift + 点击 | 添加或移除该士兵 |
| Shift + 框选 | 追加选择 |
| 双击士兵 | 选择屏幕内同阵营、同武器单位 |
| 左键空地 / Esc | 清除选择 |
| 右键敌人 | 命令当前选择的单位攻击指定目标 |
| 右键地面 | 命令当前选择的单位移动 |
| Ctrl（Mac 也可 Command）+ 数字 | 保存当前选择为编队 |
| 数字 / 双击数字 | 调用编队 / 同时聚焦编队 |
| Shift + 数字 | 将编队加入选择 |
| F8 | 将所选阵营交还 AI |

未自定义的 1、2、3 保留沙盘中绿色、蓝色、红色整队快捷选择。东线只允许玩家选择绿色部队。没有选中单位时，右键不会误指挥整个阵营。暂停时仍能选择和下达命令，恢复后执行。

## 镜头

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 按屏幕上下左右平移 |
| Shift + 移动键 | 加速平移 |
| 鼠标贴近游戏画面四边 | 贴边滚屏；B 开关 |
| 中键拖动 | 平移镜头 |
| 滚轮 | 以鼠标所指桌面位置为中心缩放 |
| PageUp / PageDown | 以画面中心缩放 |
| Q / E | 旋转镜头 |
| Alt + 左键或中键拖动 | 旋转并调整俯仰 |
| F | 聚焦选中单位 |
| Home | 恢复当前视角位置；东线回到补给起点 |
| Backspace | 恢复当前视角角度；快速再按恢复视角及缩放 |

东线玩家模式默认自由镜头，手动移动、旋转、缩放或聚焦会退出自动跟随。边界随已加载地图更新，不再被办公室原有范围限制。离开游戏焦点会清理拖拽和持续按键，避免镜头继续漂移。

旧键位调整：A 用于向左平移，交还 AI 改为 F8；E 用于旋转，贴边开关改为 B。选择、框选与平移可穿过非交互 HUD 区域，真正的按钮仍保留点击行为。

## 实现与验证

输入与镜头适配器为 `scripts/rts_controller.gd`，所有战术命令仍由 Godot 的权威 `game.command` 校验并执行。单位拾取使用实际高度投影，支持二楼士兵；选中单位、编队、拖动状态及最近右键执行结果可从状态中的 `rts` 字段核对。

- [真实浏览器输入报告](evidence/rts-controls/web.json)：31 项，通过真实鼠标与键盘验证普通战场及东线；包括右键后的实际单位移动，无 JavaScript、Godot 或 WebGL 错误。
- 原生契约测试：`godot --headless --path . --script tests/rts_contract.gd`。
- 浏览器回归：先启动测试服务，再运行 `RTS_TEST_URL=http://127.0.0.1:8787 node tools/rts_browser_qa.cjs`。
- [普通战场截图](evidence/rts-controls/sandbox.png)、[东线截图](evidence/rts-controls/eastfront.png)。
