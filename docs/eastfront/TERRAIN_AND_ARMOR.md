# 东线地形组合与装甲推进

2026-09-21。默认仍为 **DeepSeek 慢脑 + Laya 本地快脑**，JEV 使用相同意图合同。Godot 独占真实战斗状态。

## 修复原因

此前慢脑只能从 6 个固定三沙包模板选择，无法输出具体建筑布局。坦克导航把低沙包和房屋统一设成不可通行，清场时又直接退出决策；快脑如果一直只部署绿色坦克，红色预备坦克可能永远待命。

现在南北宽度从 1.4 米扩大为 **2.8 米**，东西每段长度仍为 1.45 米。桌面、导航边界、组件校验、标签、装甲入口和默认镜头同步调整。继续使用当前段交战、下一段并行施工的缓冲机制。

## 慢脑可以构造什么

| kind | 真实效果 |
| --- | --- |
| sandbag / trench | 步兵保护工位；坦克可以压毁，留下碎片、扬尘并更新导航 |
| house | 两层外观、有窗、门、楼层线的可破坏民房；提供外围硬掩体 |
| bunker | 较高耐久的混凝土碉堡和射口外观 |
| wall / ruins | 砖墙、残垣；阻挡弹道与通行，可被爆炸破坏 |
| rock | 不可破坏岩石，坦克必须绕行 |
| fuel_depot | 油桶料站，毁坏后进入真实爆炸队列，可连锁破坏并伤及双方 |
| mud | 行军速度乘 0.55 |
| road | 行军速度乘 1.15 |
| water | 不可涉渡区域，步兵与坦克导航均阻挡 |

目录在 `data/frontier_components.json`；施工外观由 `scripts/frontier_geometry.gd` 构造，沿用项目 MIT 许可。未覆盖现有 Blender/GLB 资产。施工人员继续使用当前塑料玩具兵蒙皮与骨骼。

旧 `template` 用作兼容的布局类型标识。实际双脑必须输出 `layout`：每段 3–8 个组件，自选位置与尺寸；三段合计至少 4 类组件，且必须包含房屋、碉堡或燃料建筑。UI 显示真实组件名称，来源仍为实际模型调用与引擎回执。

```json
{
  "theme": "village",
  "objective_z": 0,
  "components": [
    {"kind":"house","x":0.42,"z":-0.8,"width":0.30,"depth":0.36},
    {"kind":"trench","x":0.65,"z":0,"width":0.075,"depth":0.34},
    {"kind":"bunker","x":0.97,"z":0.78,"width":0.30,"depth":0.32},
    {"kind":"fuel_depot","x":0.85,"z":-0.75,"width":0.15,"depth":0.20},
    {"kind":"mud","x":0.40,"z":0.65,"width":0.25,"depth":0.40},
    {"kind":"water","x":0.78,"z":-1.18,"width":0.40,"depth":0.15}
  ]
}
```

把该对象放入 `eastfront_propose.battle_plan.layout`，其余守军、装甲、施工与防守字段沿用 [双脑协议](DUAL_BRAIN.md)。坐标是当前段内局部坐标（单位米）；引擎负责加上该段的东西偏移。

- x 中心 0.25–1.25，组件左右边缘在 0.12–1.35。
- width 0.04–0.6，depth 0.04–0.8；abs(z)+depth/2 ≤ 1.32。
- objective_z 在 ±0.9 内；旗点 x=1.23，周围留 0.13 米空地。
- 不允许组件重叠；至少留 0.04 米间隔，并由引擎复核步兵和坦克贯通路径。
- 过滤掉积水、道路、泥地和燃料站之后的前 3 个安全掩体对应守军 station 0/1/2；布局至少需要 3 个安全掩体。
- 边缘越界、占用旗点或重叠的坐标可由编辑器就近校正（最多移动 0.35 米），不改建筑类型与尺寸；每次调整存入 LLM 日志 `layout_adjustments`，原始模型返回完整保留。无法校正或其他非法方案退回慢脑重规划，不改动已有战斗。

新增地形需要同时登记材质/耐久/通行属性、实现几何与行为，再补充验证。模型可以组合目录内组件，不能执行任意脚本或导入未知模型。

## 坦克执行

1. 可见待命 → 按慢脑时间表等待 → 快脑部署 → 沿合法路线缓慢驶入 → 参战。
2. 超过计划时间 8 游戏秒仍未收到快脑部署，执行器补执行该慢脑计划，事件来源明确为 `slow_plan_schedule`。玩家控制绿色阵营时不自动放行。
3. 低工事是有碾压代价的可通行格；坚固建筑和水域仍阻挡坦克。
4. 移动采用扫掠检测；接触低工事时真正扣除耐久、显示碎片和扬尘并开放导航，不是穿过仍完好的碰撞体。
5. 炮塔瞄准与车体转向保留；遇到反坦克威胁继续保持距离/后撤。存在合法射击阵位时先机动；没有阵位且敌人被可破坏建筑遮挡时炮击障碍，仍走同一条射线、弹丸和爆炸路径。
6. 清掉敌人后绿色装甲继续跟随当前夺旗目标，不再无限原地等待。履带移动会给近处队员让路。

守军按前 3 个安全掩体分工找掩体；后撤只选择仍存活的守军工位，不会误把末尾燃料站作为掩体。
