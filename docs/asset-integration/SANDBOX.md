## 数据与编辑

`data/sandbox-maps.json` 是运行时地图数据源。每个 level 包含 id、name、bounds、floor_color、spawns、tank_spawn、target、objective 和 objects。对象指定位置 [x,z]、尺寸 [width,height,depth]、颜色、旋转、碰撞、可破坏标记；建筑屋顶可以添加 elevation。坐标单位是米，Y 向上。

地图选单自动读取 JSON 中的名称。新增汉字后，运行 `tools/build_ui_font.py` 并将 `source/fonts/DeskfrontUI.otf` 复制至 `assets/fonts/`，更新 UI 字体子集。原字体和 SIL OFL 许可保留在 source/fonts；发布包包含字体许可。`tools/build_maps.py` 可重建这三份默认布局；直接编辑 JSON 后不要再运行生成器，否则会被默认布局覆盖。

- `scripts/sandbox_map.gd`：读取地图数据、生成几何/碰撞、替换旧地图、处理箱体命中隐藏。
- `preview.gd`：桌面碰撞、镜头、地图切换、出生点、武器试射。
- `scripts/toy_actor.gd`：ragdoll 碰撞代理改为递归读取同一 World3D 中的 StaticBody3D，包含嵌套地图掩体。
- `tools/build_sandbox_office.py`：自包含的 Blender 场景生成器。
- `source/sandbox-generated/office-sandbox-editable.blend`：保留单独物体，适合继续手工编辑；`office-sandbox.blend` 为按材质合并的输出工程。
- `assets/models/office-sandbox.glb`：Godot 使用的场景模型，原创 CC0。原 office.glb 未修改。

新增地图时保持 bounds 位于长桌上；出生点要避开物体，坦克需留出完整车体占地。正式集成时复用新 GLB、地图 JSON、地图构建器，并将主游戏单位/AI/导航接到新布局，而不是把预览脚本当作完整关卡规则。
