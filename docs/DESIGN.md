# 桌面前线 · Deskfront

## 目标与范围

原创开源、数据驱动的单关卡 3D 战术游戏。复古办公室仍然在正常运转，右侧桌面上三支玩具小队争夺一枚黄铜目标。保留灰绿、奶油白、木色和塑料材质的比例反差。首先提供高位斜俯视，支持办公室全景、战术近景及正俯视切换。

首版是完整可玩的垂直切片，不声称达到商业 RTS 的内容量或参考图离线渲染的精度。玩家可以接管三个阵营中的任意一个、选择士兵/整队、移动、攻击、抢占掩体、撤退和交还 AI。目标积分或歼灭触发胜负，可重新开始。

## 叙事与循环

布阵 → 三方抢占中央目标 → 红方生命/战局进入劣势 → 后方坦克增援 → 路障与掩体变化 → 获胜或失败。人类缓慢打字并微动头部，不参与战斗。红方坦克仅一次增援；策划台可手动触发用于演示。AI 不通过偷偷扣血来强制剧情。

## 战斗

每队三名士兵，统一可蒙皮骨架，阵营塑料材质区分。动作语义包括待机、行进、瞄准、射击、蹲伏、卧倒、换弹、倒下。朝向性掩体只有从正确一侧承受攻击时减伤；绕侧会失效。站位预约互斥。压制累积会减速、影响命中并促使 AI 寻找保护。高障碍遮挡射线。路径使用共享栅格 A*，动态路障变化会重建阻挡。

小队决策和单兵执行分层：小队评估守点、占领、绕侧与撤退，单兵选择可达站位，保留站位直到新命令/死亡/破坏。玩家与 Agent 指令通过同一校验入口；AI 不覆盖人工控制的阵营。

## 控制台

深色本地网页，与实时 Godot 画面并排。包含小地图、单位状态、阵营控制权、最新决策及理由、候选战术评分、观察/计划/校验/执行链、参数调节、暂停/速度/重置、坦克触发和事件记录。控制结果等待 Godot 回执，排队不等于成功。

## 验收

1. Blender 原始模型可重建；Godot 中存在有效 Skeleton3D、Skin、动画及三阵营材质。
2. 九名士兵真实移动/射击/损伤，能利用方向掩体和预约站位。
3. 玩家接管后 AI 不抢控制权；交还后继续决策。
4. 人类打字循环在真实引擎帧中推进。
5. 坦克仅一次生成，能改变可破坏掩体和导航。
6. 本地控制台读写实际状态，非法/过期 Agent 动作被拒绝。
7. 积分胜负、暂停、重开闭环通过语义测试；Web 真输入与导出验证。
8. MIT 源码、CC0 原创模型、设计/工程/资源/API/交付文档齐备。

## 边界

Jev 的真实服务协议和凭据尚未提供；交付通用本地状态/动作协议与适配示例，不伪称已联通。首版不包含联网对战、复杂全身 IK、大规模军队或逐碎片破坏。不开通付费生成服务。

| 所有步兵刺刀 | 0.075米内自动近战；换弹中仍可反击 | 29伤害、0.85秒间隔、不耗弹、对坦克无效 |
| 坦克炮 | 可见炮弹与范围爆炸 | 射程0.98米、24伤害、3.4秒间隔 |

这是单一单位固定配装，不是运行中切换枪械的装备系统。玩家可以选择对应士兵进行分工。攻击指令先进入射程再停步，移动指令可用于主动拉近或避开交火。

AI开局寻找保护站位，先稳住至少6秒；能交火时保持掩体，无法交火时通过前沿沙包向目标推进。失去掩体后重新寻找近处可达站位，避免反复冲向目标中心。严重受损小队撤退。三方仍会集中火力攻击最近的威胁，首版没有完整班组交替掩护调度。

操作反馈包含地面指令环、目标攻击环、选择框、兵种/弹药HUD、枪口焰、曳光、火箭尾烟、爆炸冲击环、碎屑和音效。视觉服务只管理效果，真实弹丸落点和伤害由固定物理帧统一处理。
