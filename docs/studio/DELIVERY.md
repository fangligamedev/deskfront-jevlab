# AI 创作沙盒交付报告

日期：2026-09-19。交付状态：本地功能闭环完成、真实模型体验已验收；最终提示词修订的再次在线验证受供应商欠费阻塞。本报告最初对应本地验收；源码现随 main 更新，未创建或移动历史发布标签。

## 交付内容

- 项目重新定位为 AI 创造关卡、操纵游戏、总结战局的 Godot + Blender 开源沙盒。
- 同一 DeepSeek 配置用于关卡设计、逐兵/坦克指挥、战场分析，三个角色均记录真实模型输入及原始返回。
- 新增 AI 创作沙盒窗口：自然语言创作、JSON 导入/编辑、布阵预览、阵营与对手选择、进入关卡、态势与战后报告、JSON 导出。
- Python 严格数据校验与真实 Godot 导航预检；引擎载入时再次校验。非法方案不替换当前对局。
- 自定义关卡初次载入暂停，供玩家查看部署；重开保留关卡和控制方式，换回默认地图解除自定义配置。
- 本机 SQLite 保存关卡、任务、战局时间采样、分析和调用日志。战后自动报告按 run_id 去重，历史报告不会被新对局覆盖。
- 提供 JSON Schema、标准库 CLI、HTTP API、示例与自动测试。

## 明确边界与待评估项

首版基于三张已有地形创建部署与掩体布局，尚不生成任意游戏规则、美术或建筑。通路检查证明可达，不证明战术平衡、趣味性或每个建筑入口均未受影响；需进一步做布局质量和玩家难度评测。

原始模型报告存在方位和战术因果表述不严谨的问题。已在最新提示词中明确坐标系，并将设计意图与实际事实分开，UI 提示模型分析需要核对。引用存在与结构正确不等于每句分析正确，不应把“遭侧翼攻击”等模型解释当成已逐帧验证的事实。

最终重新生成报告收到供应商 HTTP 403 / `AccountOverdueError`，因此最新坐标与意图提示词未能完成再次真实调用验证。已增加安全错误码与中文欠费说明，需用户补足火山账户余额后重试。之前成功的关卡与报告仍能读取，游戏 AI 与 JSON 导入仍可使用。
