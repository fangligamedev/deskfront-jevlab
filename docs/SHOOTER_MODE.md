# 单兵接管：RTS / 第三人称 / 第一人称

在战场中选中一名存活步兵，点击「第三人称接管」「第一人称接管」，或在游戏画布内按 F6。点击画面锁定鼠标后开始操作。暂停时先继续游戏。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 冲锋 | Shift + 移动 |
| 转动视线 | 鼠标 |
| 开火 | 左键，支持按住连续射击 |
| 精确瞄准 / 掩体探身 | 按住右键 |
| 蹲姿切换 | C |
| 进入 / 离开附近掩体 | E |
| 换弹 | R |
| 向准星位置投掷手雷 | G |
| 第一 / 第三人称切换 | V |
| 返回 RTS | Tab / F6 |
| 释放鼠标 | Esc；再次点击画面重新锁定 |
| 暂停 / 声音 | Space / M |

## 掩体与动作

E 寻找 0.20 米内、能直线接近且未被占用的实际掩体槽位。角色使用根运动走到槽位；低矮书堆后蹲下，右键站起射击；高掩体按角落槽位侧向探身。松开右键收回，移动或 E 离开。掩体破坏后失去掩护。

移动沿用已集成的根运动、碰撞与贴地系统。身体朝行进方向，冲锋时不能开枪；侧向或后向移动时，枪口与视线夹角过大也不能开枪，避免把整个人扭成不自然的姿势。当前版本尚未提供独立的八方向持枪移动动画；停止移动后可以自由瞄准。

第一人称复用当前武器模型作为镜头内展示，隐藏自己身体以避免头部遮住相机；真实弹道仍从士兵枪口发出，不能通过镜头越过掩体射击。尚未制作独立第一人称手臂动画。第三人称镜头检测遮挡。坦克、操炮中、驻楼中及正在投雷的单位不能直接接管，需要先恢复为可自由移动的步兵。

## 与 AI 的边界

只接管选中的一名士兵，阵营原有的 game_ai / lm / player / agent 配置保留，队友按原模式行动。被接管的士兵公开 `direct_controlled: true`，`available_actions` 为空。模型控制器停止为它发起新决策；引擎拒绝已在途、试图改变玩家单位的模型命令。退出接管后重新交还原控制模式。

所有弹道、碰撞、伤害、弹匣、换弹计时、手雷库存和爆炸仍由 Godot 计算。鼠标射击通过 `combat_fx.launch_point`，与 RTS 使用同一弹道实现。返回 RTS 时，已开始投掷的手雷仍会在动画释放点发射一次。

## 工程入口

- `scripts/shooter_controller.gd`：输入、接管生命周期、镜头、掩体、玩家射击和 HUD。
- `game.gd`：在同一个物理循环中分派玩家控制或单位 AI；接管前后切换镜头。
- `unit.gd`：控制权标记、自由目标手雷交接。
- `toy_actor.gd`：原有根运动和有限上身俯仰。
- `dashboard/shooter.js`：控制台入口，发送 `possess` / `release_unit`。
- `tests/shooter_contract.gd`：战斗和控制权检查；`tools/shooter_browser_qa.cjs`：真实 Web 输入。

本地控制台命令示例：`{"action":"possess","unit_id":"green-2","view":"first","faction":"green"}`。应带当前 `instance_id` / `run_id` 发送 `/api/command`，再读取执行回执。外部 Agent 无权调用接管或释放镜头命令。
