# 工作视图

策划网页、战术执行和独立游戏专页共享同一套真实引擎接口。

| 入口 | 用途 |
| --- | --- |
| `/?view=overview` | 完整策划、AI 创作、模型配置状态、日志和参数 |
| `/?view=execution` | 大场景、阵营控制、战术指令、单位状态与执行回执 |
| `/?view=game` | 放大的游戏专页，适合独立浏览器窗口 |
| `/?view=eastfront` | 无尽东线：视口内游戏 + 独立滚动的指挥 / 调试侧栏 |
| `/?view=demo` | 双人桌面演示导演，建场、派兵、夺旗、录像与复盘 |

顶部切换策划/执行/演示只改变布局，不重载正在运行的 Godot。独立游戏按钮提供两种行为：当前页面放大保留本局；创建独立窗口会启动新局，打开前会明确提示。其他网页自动跟随运行实例，继续发送指令。独立窗口关闭后，点击“在网页重新开始”恢复内嵌游戏。

每个服务端口同时维护一个活动引擎。不同测试局请使用不同端口，避免互相接管。内置浏览器可能把弹出窗口作为标签页，或拦截弹窗；可使用对话框中的“打开游戏专页”链接。`?native=1` 可作为已运行 Godot 原生实例的控制台，需让其 `DESKFRONT_URL` 指向相同服务。

鼠标拖框选择、右键下令，中键/Alt 拖动平移，滚轮缩放；战术执行面板提供寻掩体、推进、撤退、手雷等按钮。执行限制、归属与战斗状态由引擎验证。

## 东线全屏布局与 Debug Version

游戏右上方新增蓝色「打开 Debug Version」，将右侧指挥栏切换为同局调试栏，并开启真实路线可视化；关闭后恢复原控制面板。不会重新创建 iframe、重开关卡或改变士兵控制权。日志与路径卡复用原调试数据。

桌面宽度大于 900px 时，导航占用实际高度，游戏填满剩余空间，底部操作始终留在视口内。右侧面板独立滚动；窄屏采用上下布局。「全屏游戏」先展开为满窗口视图，再请求浏览器原生全屏；浏览器拒绝或退出原生全屏时仍保持满窗口，可按「返回东线」恢复双栏。

「重置镜头」恢复东线战术近景并重新跟随远征队。东线镜头预设跟随当前小队位置，最大缩小范围从办公室的 12 限为 3.6，避免把桌面战场缩成小块；其他地图仍保留办公室镜头范围。

验证：1440×900 与 1280×720 页面滚动尺寸分别等于视口尺寸，底部重开按钮分别位于 y=894 / 714；1280×720 全屏模式游戏面板从 (0,0) 起占满 1280×720，底部按钮在 y=712。真实网页点击 Debug 开启路径、点击重置镜头均收到引擎回执。RTS 契约 21 项、语义 113 项、Python 90 项及 Forge 检查通过。测试使用独立 8795 端口，未重置 8794 的用户对局。
