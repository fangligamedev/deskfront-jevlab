# AI 战术沙盒：创造、操纵、复盘

定位：开源的 Godot 战术游戏沙盒。一个已配置的 LLM 连接承担关卡设计师、战斗指挥官、战场分析员三种角色；玩家可接管任意阵营。

首版范围：使用现有三张地图的桌面和道具资产，LLM 生成数据化掩体布置、三方出生部署、装备与中央守旗规则；静态规则和 Godot 实际导航均校验通过才能加载。不会生成或执行任意代码、下载未知资源或宣称生成任意类型游戏。

交付闭环：输入关卡意图 → 生成并检查战术关卡 → 选择玩家阵营和对手控制 → 加载暂停待开始 → 对战 → 按需态势分析和自动战后报告 → 导出关卡与报告。

验收：非法关卡不破坏当前对局；九个出生点可走到旗点、掩体不堵死主路线；自定义关卡可重开；LLM 真实返回记录进统一调用日志；模型报告关联真实局次、采样事实和引用 Tick；切换局次不把旧报告混入新局；真实 Web 完成生成、加载、玩家/LLM 选择、分析及查看报告。

预算：沿用现有 DeepSeek 连接与逐兵调用上限；关卡生成最多两次尝试（失败反馈后一次修正），一次分析/战后报告一次调用，服务端限制并发和频率。新增资源为代码与 JSON，不新增媒体服务费用。保留本工作区已有资源与动画改动。
